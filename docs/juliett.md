Opening
Film Roulette is a website where users are able to browse a collection of movies and search them based off title, director, genre, and year. 

This application uses a built in database that holds the movies and all of its information. This website also makes use of mongodb thats holds data for the roulette wheel. This application also use TMDB API to show movie ratings 

live application 
https://film-roulette.onrender.com

There will be an admin account that is used to change the movie database
