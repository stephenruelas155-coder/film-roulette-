# film-roulette-

Project — Film Roulette | film library and randomizer 
Team —- Stephen Ruelas 
User story — As a movie enjoyer, I want a place where I can view several movies in one location with details and reviews, so that I don't have to look through several websites to decide if a movie is right for me. 

Specific user / audience — My friend Mike often gets overwhelmed trying to look for a movie to watch when they are bored and has to look at several ratting websites to see if a movie seems worth his time. He is also indecisive as he has a hard time choosing a movie to watch.

Problem / Opportunity — I want to create a system where people can explore movies based on genre, ratings, release year, director, or IP without going through multiple websites. I want to also have a system where users can choose multiple movies and place them into a wheel that randomly chooses a movie for them to watch. 

Value proposition — This will make finding movies much more convenient by showing info that people can look at a glance to know if it's a movie for them. If they are unsure which movies they want to watch they can use the roulette wheel to choose a movie for them. 

Landscape — There is the site letterboxd that lets users sign in and create a collection of films you have watched, it can also watch movies as watched later and reviews are mainly left by users. This site mainly relies on users to review movies but it doesn't show ratings from other sources like movie critics. There is also not a randomized system for movies but a ranking system made by other people.

There is also IMDB that has a collection of movies that separates them into categories that also lets users review them creating its overall rating. It also goes further showing the cast and director who worked on the movie. Still the ratings are only from one set of users and people can not save movies that seem interesting to them. It also does not mention where a person can watch these movies.

Filmaffinity is another site where users create their rate and recommend movies to one another. It also has a system to filter movies or search for a specific one.
Done — The project will be considered complete when a user is able to search either using the search bar or the filters and can then place the saved movies and they go into the roulette wheel and choose a movie at random. 

Plan — 

Starting Point — I need to create and display a database of movies with each one having categories like genre, IP, director, release year and where it can be watched.

Direction — This program will be able to show a massive movie database that users can look through and select a set of movies with one being randomly selected.

Capabilities — This can use the api of different sites to display rating information. It holds a database that is filed with movies. 

Biggest unknowns — I am unsure how to implement the api of other sites into my site.
